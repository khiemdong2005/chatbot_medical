# Tài liệu lịch sử

Các bản khắc phục Gemini, roadmap, đề xuất workshop và sơ đồ dự án cũ được giữ
để tham khảo quá trình phát triển. Chúng có thể nhắc đến cấu hình, đường dẫn hoặc
tính năng đã thay đổi và không phải hướng dẫn triển khai hiện tại.

Khi cài đặt hoặc đóng góp, xem [README hiện tại](../../README.md),
[kiến trúc](../architecture.md) và [hướng dẫn đóng góp](../../CONTRIBUTING.md).
