# Bản thiết kế tham khảo

`medimind-redesign/` giữ các artboard HTML và `canvas.json` của quá trình thiết kế.
Các file này là tài liệu tham khảo; website chạy từ `templates/` và `static/`.
Các artboard và đường dẫn tương đối trong canvas được giữ cùng một thư mục.

Git lưu phiên bản thiết kế. History và cache do trình chỉnh sửa tạo ra được giữ
cục bộ, không đưa vào Pull Request.
