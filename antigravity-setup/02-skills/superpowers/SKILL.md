# Superpowers Skill

## Quy trình 3 bước bắt buộc:
1. **Lập Kế Hoạch (Plan-First)**:
   - Trước khi sửa bất kỳ dòng code nào, phải phân tích rõ nguyên nhân gốc rễ và đề xuất phương án tối ưu.
   - Trình bày kế hoạch từng bước cụ thể.
2. **Kiểm thử Trước (Test-Driven)**:
   - Viết bài kiểm thử (pytest hoặc vitest) mô phỏng các ca biên (edge cases) trước.
   - Chạy test xác nhận test FAIL khi chưa có code.
3. **Triển khai Tối thiểu & Refactor**:
   - Viết code tối thiểu để pass test.
   - Refactor mã nguồn đảm bảo clean code, type hints và không duplicate logic.
