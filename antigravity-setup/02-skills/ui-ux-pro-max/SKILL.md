# UI UX Pro Max Skill

## Quy tắc thiết kế bắt buộc:
1. **Kính mờ Liquid Glassmorphism**:
   - Sử dụng `backdrop-blur-xl` hoặc `backdrop-blur-2xl`.
   - Nền bán trong suốt: `rgba(15, 23, 42, 0.75)` hoặc `bg-slate-900/60`.
   - Đường viền phản chiếu ánh sáng: `border border-white/10`.
   - Đổ bóng chiều sâu: `shadow-[0_8px_32px_0_rgba(0,0,0,0.36)]`.
2. **Bố cục Không gian (Spatial Layout)**:
   - Floating Capsule Dock ở mép trái.
   - Header dạng Pill nổi (Floating Header Pill).
   - Tách biệt rõ ràng 3 cột: Left Panel (3/12), Center Stage (6/12), Right Telemetry (3/12).
3. **Typography & Màu sắc**:
   - Chữ chính: `#FFFFFF`, Chữ phụ: `#94A3B8`, Viền: `#334155`.
   - Màu nhấn (Accent): Cyan `#38BDF8`, Violet `#A855F7`, Emerald `#34D399`, Amber `#FBBF24`.
