# 16. Chrome DevTools MCP — Phân tích lỗi và hiệu năng web

## 📌 Tổng quan
Kết nối trực tiếp phiên làm việc của Antigravity với Chrome DevTools qua Puppeteer. Cho phép đo lường chỉ số Core Web Vitals, kiểm tra Network waterfall, bộ nhớ heap và audit hiệu năng tải trang.

## 🚀 Cài đặt Plugin chính thức
Trong Antigravity Plugin Marketplace:
* Plugin ID: `antigravity-plugins-official/plugin/chrome-devtools-plugin`
* Cung cấp khả năng kiểm thử console, DOM inspection và phân tích Network tab trực tiếp.

## 💡 Mẹo dùng với Antigravity
* Yêu cầu Agent đo lường FPS và thời gian render DOM của các hiệu ứng kính mờ Glassmorphism để tối ưu CPU/GPU.
