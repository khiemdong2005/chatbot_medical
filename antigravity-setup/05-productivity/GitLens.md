# 30. GitLens — Xem lịch sử Git ngay trong IDE

## 📌 Tổng quan
GitLens là extension huyền thoại cho VS Code / Antigravity IDE. Tăng cường khả năng quan sát mã nguồn với tính năng Git Blame theo từng dòng code, xem ai đã sửa dòng này, commit nào, ngày nào và lý do là gì.

## 🚀 Cài đặt trong Antigravity / VS Code
* Mở Extensions (`Ctrl + Shift + X`).
* Tìm kiếm `GitLens` và nhấn **Install**.

## 💡 Mẹo dùng với Antigravity
* Sử dụng GitLens Revision Navigation để so sánh phiên bản code do AI sinh ra với phiên bản trước đó chỉ với 1 click.
