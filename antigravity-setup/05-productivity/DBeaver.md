# 29. DBeaver — Quản trị và truy vấn cơ sở dữ liệu

## 📌 Tổng quan
DBeaver Community Edition là công cụ GUI quản lý cơ sở dữ liệu vạn năng, hỗ trợ hầu hết các hệ quản trị CSDL phổ biến: SQLite, PostgreSQL, MySQL, MariaDB, SQL Server, MongoDB và DynamoDB local.

## 🚀 Cài đặt trên Windows 11
```powershell
winget install dbeaver.dbeaver -e --source winget
```

## 💡 Mẹo dùng với Antigravity
* Dùng DBeaver để mở trực tiếp file SQLite cục bộ (`database.db` hoặc `users.db`) của dự án để xem dữ liệu bệnh nhân và đơn thuốc trực quan dạng bảng Excel.
